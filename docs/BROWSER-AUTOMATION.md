# 内置浏览器与 AI 操作

实现路线：继续使用 Electron `<webview>`、既有 guest 租约和 `persist:` 分区。生产控制不依赖 Playwright，也不采用 DSH 插件接入体系。Playwright 仅用于开发验收。

## 使用

1. 在「网页工作台 → 浏览器」输入 HTTP/HTTPS 地址或搜索词；搜索词打开 Google 搜索。地址栏会显示匹配历史，支持方向键、回车、Escape 和清空。小红书专用页仍在「自媒体 → 我的小红书」，保留官方域名限制、只读地址栏和独立登录分区。
2. 在右侧现有 AI 助手直接提出要求，例如“查询本月订单，核对查询结果”。关联浏览器页面的对话自动获得当前活动标签的操作能力，无需独立目标输入框或启动按钮；模型须已在设置中启用。不另显示网页关联提示行；发送时自动读取并绑定明确标签，标签关闭后报错，不默默改用别页。博客对话进入“我的小红书”时保留当前或固定的文章，并组合博客建议与网页工具；填写网页不会改写本地博客，本地修改仍走建议确认。空标签可通过对话打开指定网址；打开新站点仍需授权。其他工作台聊天不因此获得全部浏览器权限。
3. AI 通过明确的标签 ID 读取和操作。访问新来源（协议、主机、端口的组合）时暂停；点击工具栏的「等待站点授权」或「⋯」，在菜单核对完整站点后点击「允许此站点」才继续。
4. 可点击页面接管，或使用「接管 / 暂停」「继续操作」「停止任务」。切换工作台或收起 AI 助手或隐藏应用窗口不会暂停，应用运行时会继续在原 guest 操作；后台等待新站点授权时，顶部显示返回浏览器的入口。切换或新建标签保留原任务后台运行；手动导航、刷新、缩放或点击接管会暂停对应标签的任务，避免与人工操作冲突。已经发出的网页操作不能因停止而撤销；超时后先核对页面，避免重复提交。
5. 模型需要澄清、任务尚未验证时，可在同一对话和浏览器页面回答后继续。已完成、已停止、已中断的任务，可在对话提出新要求，由主进程重新绑定当前标签；旧授权不会因重启自动恢复。
6. 需要截图判断的模型，在「设置 → AI 助手」的模型列表中，点击编辑按钮旁的眼睛图标切换「多模态」，即时保存图片输入设置；睁眼为开启、划线眼睛为关闭，悬停显示说明。文字模型继续使用页面元素。普通连接测试不证明图片能力。
7. 历史记录、任务记录和清理数据统一从工具栏「⋯」打开；运行时的暂停、继续和停止保留在地址栏旁。每条新浏览器回复下方的「查看操作记录」打开该任务的真实记录，同一任务的澄清共享记录；后续任务不会替换旧回复的关联。任务记录沿用最近 40 条的保留范围，淘汰后明确提示，不改为显示其他任务。旧版回复没有逐条任务标识，仍可从菜单查阅保留的任务记录。

## 功能范围

本功能帮助用户使用网站：输入、点击、查询、导航、选择选项、滚动及核对结果。没有页面样式编辑、源码编辑、标注反馈或开发诊断入口。AX/DOM 和有限 CSS 选择器用于定位可操作元素与读取结果，不提供任意脚本或样式写入工具。

后台执行指主进程模型循环和原网页 guest 在应用仍运行时继续工作，不是退出后的独立服务；模型轮次与人工等待仍有下述时间上限。

## 执行链

```text
右侧现有 AI 对话（当前浏览器页面与活动标签）
  → PI 模型会话与七个浏览器工具
  → 主进程：窗口/任务/标签/站点校验、按标签串行执行、暂停与取消
  → 已有 guest：CDP 观察/定位/截图 + 定向输入
  → 操作后重新观察 → 条件核验 → 页面条件验证通过 / 尚未验证
```

主页面的 CDP Input 在本机 Electron guest 中存在“命令成功但没有输入事件”的情况。这里使用 `WebContents.insertText/sendInputEvent`；跨进程 iframe 使用对应 CDP 子会话输入，避免把输入投递到主页面。`guest-driver.ts` 将两者封装在主进程内，渲染器和模型均不能调用任意 CDP 方法或执行任意脚本。

| 历史与站点数据 | 地址栏历史建议/网页搜索；最近 5000 条访问记录，标题/网址搜索、时间过滤、单条删除；可选择清理历史、Cookie、站点存储、缓存及当前/分区全部站点 | 浏览器日常管理 | 历史可按时间清理，Cookie/存储/缓存目前仅按站点清理全部时间；含凭据类参数的 URL 脱敏；Cookie 存在域共享语义 |

## 网页缩放

网页缩放位于通用浏览器及“我的小红书”的「⋯」菜单：25%–500% 常用档位、当前比例、重置为 100%。`GuestFrame` 直接调用现有 webview 的原生缩放 API，并在导航、切标签、打开菜单时读取实际比例；同一持久分区内同源页面沿用 Chromium 共享缩放，不新增独立缩放存储。手动缩放会先暂停正在执行的浏览器任务；现有截图布局指纹拒绝缩放前的坐标，重新观察后按实际 zoom factor 转换原生输入。

## 主要文件

- `shared/browser-automation-contracts.ts`：严格动作/条件 schema、观察和截图、任务及 IPC 契约。
- `electron/browser-guests.ts`：已有安全载体，加稳定标签标识、受控 guest 查找与生命周期通知。
- `electron/browser/driver.ts`、`guest-driver.ts`：CDP 观察、引用、截图、输入定位和 Electron 适配。
- `electron/browser/query.ts`：使用 Chromium CSS 查询与 AX 名称，处理局部容器、有限属性、筛选和完整正文读取。
- `shared/browser-history.ts`、`modules/browser/ui/address.tsx`：地址与搜索词解析、历史过滤、地址栏建议及键盘操作。
- `electron/browser/tasks.ts`：授权、串行队列、站点等待、任务控制、核验与续话。
- `electron/browser/store.ts`：原子替换本机地址/任务记录文件；启动时把未结束任务标为中断。
- `electron/browser/ipc.ts`、`preload.ts`：主窗口文档白名单和有限 API。
- `modules/browser/ai.ts`、`electron/ai-core.ts`、`ai-ipc.ts`：模型工具、图片与现有流式对话接入。
- `modules/browser/ui/automation.tsx`、`pane.tsx`、`src/views/BrowserView.tsx`：接管、任务状态、标签与历史管理界面。

## 工具

| 工具 | 用途 |
|---|---|
| `browser_tabs` | 列出、打开、选择、关闭本任务标签 |
| `browser_navigate` | 明确标签内导航，执行分区与站点授权检查 |
| `browser_observe` | 元素、正文、frame，按模型能力选择截图；query 支持定向定位、容器筛选、元素与正文分别分页 |
| `browser_act` | 严格联合类型的元素、键盘、坐标、滚动、拖动动作 |
| `browser_wait` | 最长 15 秒的文本、URL、元素或字段状态等待 |
| `browser_check` | plan 声明不可弱化的必需核验项，verify 汇总逐项结果；旧单条件调用也累计保留失败 |
| `browser_extract` | 按列读取类型化字段、原文和来源，按唯一键跨页收集，报告完整性并分页返回 |

控制命令有 12 秒响应上限，不同对话可并发，同一对话仍只有一个请求；同一标签由一个任务独占，取消后须等待已派发操作结束才能复用；浏览器单次模型请求最多 10 分钟，人工接管等待最多 5 分钟；最多派发 75 次带记录的页面操作。输入和提交不自动重试；只读观察在页面尚未稳定时最多重读三次。

## 多对话、核验与提取

- AI 请求、流式消息、超时、澄清和取消按 chatId 隔离；停止当前对话不会停止其他对话。主助手与悬浮待办均按 sessionId 路由澄清。模型选择影响后续请求，已经开始的请求保留自己的连接参数。
- 不同标签可以并发操作；工具栏只显示当前标签任务。空白页尚未创建目标标签时仍能授权站点。切标签不会暂停原任务；实际手动修改该页、刷新和缩放仍暂停。清理共享浏览数据必须等待该分区所有活动任务结束。
- 操作前用 browser_check 的 plan 登记全部必需条件 `{id,label,condition}`，操作后 verify 汇总。可以追加条件，不能删除已有条件或更换其含义。所有条件通过才标记完成；其他对话启动不丢弃未结束清单，续话重新绑定时全部证据过期；失败、未知和过期均保留为未验证，记录弹窗显示逐项证据。兼容的单条件调用也保留之前的失败，等待接口不计入核验。
- browser_extract 的 collect 接收行 query、字段名/列号/类型/required、keyFields；返回 collectionId。翻页或滚动使用现有受控动作，再用同一集合收集。字段、查询范围或来源站点变化须新建集合。集合仅存在于当前请求的任务内存，人工暂停或请求结束后清空，续话与重启不会自动续收。
- 每个字段保留原文；数字使用严格格式并拒绝不安全整数，日期使用明确的年月日格式。缺失、截断、类型错误或同键异值均报告，不能算完整。总量必须由 totalQuery 从页面唯一读取，endCondition 确认末页；读取范围、字段、条数与末页证据全部符合时才返回 complete，否则 partial/unknown。pagesRead 统计不同页面内容批次，不代表网站宣称的总页数。
- 每个任务最多 8 个集合、每集合 1000 条；read 按 resultOffset/resultLimit 分页，每次最多 250 条且约 64000 字符，返回 nextOffset。不能把响应的当前页或声明过的总量当作实际读完。集合保存每行的页面/frame 来源、读取时间；不引入额外提取模型或任意 JS 执行。目标改变时可先停止未验证任务，再在同一对话提出新要求。

## 保存与数据边界

- 站点授权使用选定的底部待处理卡：固定在当前 AI 对话输入框上方，聊天中的“定位授权卡”将焦点移回卡片。仍可从浏览器菜单授权。授权按钮不受正在生成回复的状态阻塞，提交期间禁用并防重复；失败就地提示并可重试。
- “允许并继续”调用原任务控制接口，并附带当前展示的 origin，主进程拒绝已经变化的请求；“不允许”取消本次任务，不写入永久拒绝列表。`BrowserTask.siteApprovals` 记录 pending / allowed / denied / expired，随任务本机保存；结束及应用重启将 pending 变为 expired。允许只代表站点许可，不代表导航成功或通过目标核验。

- 分区继续使用 `persist:wb-browser-default` 与 `persist:wb-browser-xhs-creator`，不读取系统 Chrome 配置。
- `browser-state.json` 保存地址、最近 5000 条访问、40 个任务及各任务最多 80 条操作摘要；不保存截图像素。拒绝带用户名密码的地址；保留普通参数和锚点，识别到 token/code/state/API key 等凭据类参数时只保存路径。旧历史会补齐条目标识。
- 现有聊天机制会在本机 `chats.db` 保存可见工具文本，包括所读页面的有界片段。截图以图片块交给配置的模型服务，不写入可见工具文本或聊天图片字段。
- 普通和小红书分区之间不共享登录。清理站点数据需要确认，并在活动任务结束后执行。Cookie 可能在站点父域内共享；清理不等于删除线上账号或内容。
- 当前 Electron `session.clearData` 没有时间范围参数，所以不能将“最近 1 小时”伪装成 Cookie/缓存的精确清理范围；清理界面明确提示历史与站点数据的不同范围。
- 网页被视为不可信数据，不能通过页面文字取得额外工具、标签或本机文件权限。现有待办/写作建议确认机制保留。

## 验收

局部查询示例（工具参数，不是需要用户手动输入的命令）：

```json
{"tabId":"任务标签ID","query":{"selector":{"by":"role","value":"button","name":"保存"},"within":[{"by":"css","value":"#orders"}]}}
```

CSS 与元素分页示例：

```json
{"tabId":"任务标签ID","query":{"selector":{"by":"css","value":"#content_left .result"},"offset":0,"limit":100}}
```

定位方式放在 `query.selector.by`，选择器文本放在 `query.selector.value`；`query.by`、`query.selectorText` 均不受支持，观察结果本来就包含 `text` 和 `elements`。`browser_observe` 在工具执行前列出不支持的字段完整路径（包括 selector 和 within 内的额外字段），返回 `invalid-tool-arguments`、修正提示和合法示例，供模型修正后重新调用。不会自动删除字段或执行错误参数；原有严格 schema、类型和范围校验继续生效。

同名按钮可通过 `within` 容器链、`and/or`、`has/hasNot`、`hasText/hasNotText`、`visible`、`nth` 缩小范围。大页面读取使用 `offset/limit` 取得元素页，使用 `textOffset/textLimit` 取得正文段；返回 `page.totalElements/nextOffset/totalTextLength/nextTextOffset`。查询表格 `row` 或 `tr` 返回 `cells` 数组（文字、角色、截断标记），每行最多 50 列、每列 1000 字，超限明确标记。表格相邻列以分隔符匹配，避免订单号和金额拼接造成误匹配。虚拟列表和网站分页仍需滚动/翻页加载。元素引用仍只对最新一次观察有效。

`browser_act` 的 `type=locator` 提供直接定位操作：`query` 保存查找条件，嵌套 `action` 指定点击/输入等动作，`timeoutMs` 最长 15 秒。执行时重新查找并等待唯一、可见、未遮挡的目标；多匹配返回候选角色、名称、frame 和容器；指针操作检查位置动画及两次几何稳定性，已发出输入后不自动重放。它沿用现有 guest/CDP，不依赖生产 Playwright，不开放任意脚本；文字匹配支持字符串或 `{pattern,flags}`，flags 限于空/i/u/iu，正则在可取消、有超时的 Worker 中执行。

`browser_check` / `browser_wait` 共享局部定位及 `type=state` 的 attached/detached/visible/hidden/enabled/disabled/stable 条件：`type=locator` 可按 `query` 核验 `count`、字段值与状态；旧的元素/字段和文字条件也定向检索目标，不再只检查默认观察的前 250 元素或 14000 字。未授权 frame、超限正文或截断字段不能证明不存在；字段只返回前 1000 字时明确标记 valueTruncated，不能用相同前缀冒充完整字段值。

设置复选框使用 `{"type":"setChecked","ref":"最新元素引用","checked":true}`；已选中时不重复点击。逐字追加使用 `{"type":"pressSequentially","ref":"最新元素引用","text":"内容","delayMs":20}`。非 ASCII 文字逐字通过浏览器输入，不伪造 IME 组合过程。
