## v2 改动

1. 点击日历标题中的“2026年”，在标题下方展开年份下拉列表。日历仍留在原位。
2. 列表完整包含 1900–2100 年，含端点。可以滚动并直接点击年份；取消输入框、“跳转”按钮与十年分页。
3. 正常打开时定位当前浏览年份。图中第二状态专门展示列表已滚到 1990 年、尚未选择，第三状态展示选择后的 1990 年 10 月。
4. 选年只改变日历浏览年份并收起下拉，月份保持不变。选择具体日期后才填写生日。
5. 键盘方向键、PageUp/PageDown、Home/End 浏览选项，Enter/Space 选择；Escape 先收起年份下拉，再关闭日历。Tab、外部点击与窗口调整关闭下拉；不触发表单保存。中文输入法组合中的 Enter 不选择。
6. 闰日到平年仅修正浏览焦点；原生日保持不变，直到明确选择新的日期。

## 样式与实现范围

- 保留当前命例双列表单、雾灰主题和 240px 日历浮层。
- 年份选择使用应用自有下拉样式，依据 `modules/todo/ui/ui.tsx` 的共享 `Select`、`todo.css` 的 `select-menu/select-option` 和当前全局滚动条。弹层宽度对齐年份入口、列表高度有上限、滚动条可见；不依赖系统原生下拉的外观。
- 设计 HTML 是独立、离线、无产品数据的可审阅原型。未来产品实现应组合或扩展现有 `DatePicker` 与 `Select`，以命例生日的显式可选能力开启，不能另造屏幕专用选择器。
- 命例新建与编辑一致；其他日期调用、排盘算法、日期格式、出生时间和存储保持现状。
- 下拉与日历的嵌套层级、Escape 消费、焦点恢复及最小窗口避让必须在实际产品实现时验证。
