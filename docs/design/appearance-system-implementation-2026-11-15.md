# ONO 外观系统实施与验收记录

## Bot 侧栏执行动效（2026-11-17）

侧栏头像动效（2026-11-17 用户追加：参考 DS-Bot，增大幅度）：思考时侧头眯眼，搜索／读取时扫视，执行时轻跳或按角色形状扭动／压缩拉伸，交接时侧移，回复时点头。42px 头像的主要跳动约 3–5px，倾斜 8–12°；具体关键帧统一由 src/views/bot.css 持有。等待其他 Bot 时以 3.2 秒周期小幅慢摆（左右 3°），显示空心状态点及“等待协作结果”；等待用户／资源或执行中断时仅提醒一次，结束后完全静止并保留问号角标；任务真实成功后回弹 1.1 秒，失败、取消、历史数据加载不播放成功回弹。选中态与执行态独立，后台执行者继续显示自己的状态。

空闲与排队默认完全静止，不自动眨眼、歪头或舒展。鼠标进入时播放一次 600ms 的表情反馈，点击或键盘激活反馈 480ms，之后归位；鼠标留在入口内移动不持续跟随，也不重复触发。持续动作只用于真实执行或协作等待；执行时头像右下角保留实心状态点，协作等待为空心点，展开侧栏的第二行显示真实活动，静止或减少动态效果时仍能识别。空闲第二行恢复原职责；选中底色只表达当前查看对象。原切页及右键资料行为不变。只在侧栏启用，历史消息、资料和选择器静止。沿用 42px 头像、54px 点击框及现有两态坐标；不缩放导航框。页面隐藏或头像离屏暂停；30 秒无输入暂停循环，有输入恢复，有限次提醒／成功反馈不受休息计时影响，固定状态点和状态文字不因暂停而消失。系统减少动态效果取消全部动画和倾斜，悬停提示及可访问名称继续表达真实状态。图形头像沿用身体动作，不添加眼睛。

ONO 通过 BotCard.activity 接入真实流式思考、工具和回复事件，状态变化才发送 activity 通知；短暂工具阶段不人为延长。运行活动保存在 Host 内存，不改任务 revision／时间戳。仍有运行任务时优先展示执行阶段，等待确认数量独立保留；全部停下后按用户等待、资源等待、协作等待、排队、中断确定表情。completion 仅标记真实成功，首次加载和重复刷新不回弹。后台兼容版本 v6 在空闲时接替 v1–v5，旧任务运行时沿用保护；开发态需要完整重启 npm run dev。

## 已实现

- 「设置 → 个性化」提供经典/悬浮导航、纯色/普通玻璃/强玻璃和八套主题。八主题为雾珀、暖砂、青瓷、藤紫、蔷薇、燕麦、窗影和空间窗景。三项设置独立组合、实时预览、落盘并在重启后恢复；窗影的上午/午后/傍晚根据电脑本地时间自动切换。
- 经典保留一体顶栏与侧栏表面；悬浮顶栏拆为四组，左上只有 Logo 和展开按钮。两种样式共享 66px/200px 侧栏占位与顶栏控件几何，切换不移动其他内容。悬浮主导航在顶栏与独立设置按钮之间居中，窄高不足时内部滚动。二级目录保留原鼠标和键盘操作。
- 按实际界面反馈，页面标题、说明与主操作在两种导航下均使用标题卡片；完整功能使用功能卡；待办、阅读、签到、博客、游戏、AI 测试等连续工作区使用统一材质面板。已在面板内的标题与普通行不重复套毛玻璃。功能工具栏、显式组件卡片样式和控件自身底面保留。
- 三档材质使用同一组表面绑定：纯色为不透明白色实底、无模糊，普通为轻磨砂、少量透色，强档增加透色、模糊与边缘层次；不更换布局尺寸、字阶或业务组件实例。窄窗口中覆盖内容的 AI 面板在玻璃两档下提高遮挡，纯色档保持实底。未改灵动岛、终端、网页原生内容和星盘本体。
- `cool/sunny` 迁移至 `mist`，缺失的新设置落到经典/普通。保存使用三项外观快照串行写入，迟到响应不回写新选择，失败恢复最后成功值并可重试。旧 `windowLight` 字段兼容保留但不驱动显示，时段变化不写配置。其他应用设置使用原接口及存储。
- 已有看板自由布局、卡片样式、真实签到/额度、业务草稿和任务数据均沿用 v2.2.0 的实现。
