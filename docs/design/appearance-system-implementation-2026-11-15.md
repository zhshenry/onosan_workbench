# ONO 外观系统实施与验收记录

实施基线：已发布的 v2.2.0（`ae67acc`）；最初在独立分支 `codex/ono-appearance-system` 实施。2026-11-15 已将本次 UI 改动同步至日常项目目录 `C:\Myself\vibe_coding\onosan_workbench`，可在该目录启动开发版。没有发布新的安装包。

启动方式：结束旧的开发进程后，在上述目录重新运行 `npm run dev`，进入「设置 → 通用与外观」。本次同时修改 `electron/` 与 `shared/`，必须完整重启开发进程，单独刷新窗口不会重载主进程的新设置契约。原目录中的其他设计文件与 AI 助手文档修改已保留。

## 已实现

- 「设置 → 通用与外观」提供经典/悬浮导航、普通/强玻璃、八套主题及窗影上午/午后/傍晚。八主题为雾珀、暖砂、青瓷、藤紫、蔷薇、燕麦、窗影和空间窗景。四项设置独立组合、实时预览、落盘并在重启后恢复。
- 经典保留原导航几何；悬浮顶栏拆为四组，左上只有 Logo 和展开按钮。主导航在顶栏与独立设置按钮之间居中，窄高不足时内部滚动。二级目录保留原鼠标和键盘操作。
- 纯标题在悬浮模式没有卡片；完整功能使用卡片；待办、阅读、签到、博客、AI 测试等连续工作区使用统一磨砂阅读面板；内部行与小标题不重复套毛玻璃。功能工具栏、显式组件卡片样式和控件自身底面保留。经典标题卡保留为兼容例外。
- 强玻璃统一明暗边缘、柔和阴影与背景模糊；材质切换不更换布局尺寸、字阶或业务组件实例。窄窗口中覆盖内容的 AI 面板使用更不透明底色。未改灵动岛、终端、网页原生内容和星盘本体。
- `cool/sunny` 迁移至 `mist`，缺失的新设置落到经典/普通/午后。保存使用四项外观快照串行写入，迟到响应不回写新选择，失败恢复最后成功值并可重试。其他应用设置使用原接口及存储。
- 已有看板自由布局、卡片样式、真实签到/额度、业务草稿和任务数据均沿用 v2.2.0 的实现。
