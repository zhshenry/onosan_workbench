# REL049 · 游戏试玩问题的截图记录与 ZIP 导出

适用产品为 ONOSAN，归属游戏工作台。[本项进度与任务](../../README.md#游戏工作台)

## 业务目标

用户能在试玩中记录问题、附带截图并导出 ZIP 便于后续排查。

## 验收条件
