# 窗口内展开试玩

2026-10-20 用户选择顶部细栏稿，参考本目录 `design/game-preview-expand-approved.png`。仅改变 Ono 工作台主体内的预览布局，不修改游戏源码或进入操作系统全屏。

## 操作

1. 本地启动或配置线上地址后，点击预览尺寸右侧、「⋯」左侧的「窗口内展开」图标。
2. 保留全局顶栏与一级图标栏，隐藏二级目录、项目栏、原预览工具栏、测试栏及终端。细栏显示项目、当前环境、模式、刷新、截图记录与还原布局。
3. 当前环境临时使用跟随窗口的承载尺寸，保留同一浏览器页面、网址、历史、进度与原生缩放。
4. 点击「还原布局」恢复原尺寸、检查宽度与终端开合；PowerShell 会话继续运行。焦点回到原展开入口。

「截图记录」沿用现有截图保存，不自动刷新或提交问题；退出展开后可从附件/问题反馈使用截图。「刷新」由用户主动重载当前环境，并沿用已有的本地代码更新提示。当前环境没有页面时禁用展开。展开后当前本地服务停止或页面载入失败，仍可还原或重试。

本地和线上分别保留自己的原尺寸与存档。切往其他工作台后其正常布局不受影响，返回继续本次展开。Escape 留给游戏和现有弹窗使用，不新增全局退出快捷键。

## 实现与验收

`src/views/GameView.tsx` 管理本次展开状态并复用原 GamePreview；不改变 guest key、租约、地址或分区。`src/views/game.css` 的展开态选择器仅在当前游戏宿主可见时隐藏二级目录，并保留共享主题、字体、按钮焦点和窄窗还原操作。
