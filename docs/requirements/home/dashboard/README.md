# 首页自定义看板

页头标题按个人资料昵称显示「{昵称}的看板」，空白昵称回退「我的看板」。保存昵称成功后立即同步标题、问候与头像，复用原昵称来源与保存流程。

2026-11-13 用户选择自由网格方案，视觉依据为 [确认稿](../../../../design/home-dashboard-grid-selected-2026-11-13.png)。2026-11-14 按后续确认更新为三类多样式目录：[待办摘要](../../../../design/dashboard-catalog-today-selected-2026-11-14.png)、[每日签到](../../../../design/dashboard-catalog-checkin-selected-2026-11-14.png)。

首页布局识别待办摘要、日程待办统计、专注计时、每日签到、AI 额度。添加目录按用户后续要求移除专注栏目，将待办摘要、日程待办统计合并为「日程待办」，与每日签到、AI 额度共三个分类；已有专注卡片、计时及原默认布局不变。新统计卡默认四列两行，仅在显式添加后进入草稿，不自动插入已有或默认看板。待办摘要提供完成与待办堆叠图，新统计卡提供日程与待办对比图；今日安排和最近完成退出目录，旧配置仍可显示，打开目录预选堆叠图，取消不改写，明确应用后才转换且保留原宽高。签到目录仅提供带图标的列表和应用卡片，应用并排与领取进度退出添加目录和更换样式；已有配置兼容显示，打开目录时这两种旧样式预选列表，取消不改写，明确应用后才转换且保留宽高；额度仍为进度条／圆环／列表。不再提供常用入口与阅读清单卡片，原页面和业务数据保留。

卡片可添加、移除、拖动或方向键调序；编辑模式的四条边均可拖动，左右调宽、上下调高，向外增大、向内缩小，自动吸附固定档位，替代原右下角调宽图标。每种卡片一张，宽度为 2／3／4／6 列，高度为 1／2／3／4 行四个固定选项；高度分别为 180／260／340／420px，宽度随画布等分，窄容器自动重排。拖动显示「列 × 行」尺寸；上边调高固定底边，下边调高固定顶边，上边缩高产生的顶部留白按 80px 步长保存，未定位布局向上扩展不越过所在网格行顶部，定位后可使用画布内可用空位且不覆盖邻卡。松手保留位置，完成重载后恢复；Escape 或指针中断同时撤销本次高度和位置变化；左右柄支持左右键，上下柄支持上下键，Home／End 到最小／最大档。窄窗中相同渲染宽度保留原档位，不因轻微拖动改变不可见的尺寸差异。删除其他卡片不改变原有卡片尺寸；空余高度不自动分配。卡片上的铅笔编辑按钮统一移除，顶部保留「编辑布局」；目录仍提供添加与已有卡片的样式／尺寸选择，已有卡片只更新设置，支持取消。编辑期间业务按钮不可触发，拖动松手只更新草稿，点击主页面「完成」才保存，主页面「取消」恢复原布局。

目录按 2026-11-14 用户后续要求改为按钮下方的紧凑非模态浮层：520px 宽、最高 440px，无全屏遮罩，三个分类等宽横排，520px 以下两列，保留当前可用样式和尺寸选项，日程待办分类同时提供两种图表的真实预览。可点击外部、再次点击触发按钮或按 Escape 收起；关闭恢复合适的焦点。空间不足时自动约束位置和高度，预览与尺寸区域内部滚动，分类及底部操作持续可见。收起目录不保存未应用选择，应用仅更新布局草稿，完成仍由主页面显式保存。

按用户后续“所见即所得”要求，预览直接复用首页 `DashboardCard` 和内容组件；根据当前网格与所选宽高确定真实尺寸，再缩小放入 96px 高的预览视口。标题、图标、字体、底部操作和响应式布局不再另设简化版本；尺寸选择即时反映在预览。内部内容 inert，样式按钮为同级覆盖控件，不执行签到或导航。预览对应保存后的普通卡片，编辑把手与移除工具仅用于布局编辑。

「日程待办」分类并列提供两图，切换到其他分类后再返回，保留本次选择和尺寸。目录入口合并，原摘要与统计卡片各自的 ID、已有顺序、宽高与统计口径不变，允许同时保留；应用只添加或更新所选图表，不替换或删除另一张。取消与保存边界沿用原流程。

AI 额度三种样式完整显示 Codex、Z Code、Cursor、Grok Bot 四个来源，未连接项也保留原位，使用原品牌图标和既有色彩 token。进度条与紧凑圆环默认为 2×2，卡片内容宽度达到 600px 时四列；列表为账号、周期／状态、剩余值对齐的四行。默认两行高完整显示四项，一行小卡按需局部滚动，不截断来源数量。未连接时保留完整轨道或圆环，以连接符号表示未知值；0% 继续作为真实值显示。更新延迟、恢复中及连接异常标明状态且保留缓存。最低剩余窗口的计算、真实接入数量与账号设置入口沿用既有实现，预览和首页保持相同布局。

每日签到新增「应用卡片」样式，仿照额度的浅色品牌单元，显示 WorkBuddy、Qoder、TRAE CN 及真实状态；确认领取后展示真实奖励，未知金额用「—」，未确认时不显示成功奖励。窄卡两列且第三项整行，240px 以下单列；280px 以下隐藏底部汇总计数，保留各平台状态及两个操作，600px 起三列。预览与首页共用内容和响应式布局，一键签到及管理账号继续复用原操作；默认并排样式不变，仅用户明确应用并完成保存后切换。

本机布局由 `shared/dashboard-layout.ts` 定义，存于 `wb.home.dashboard`；恢复时校验类型、宽度、高度与样式。旧布局保留顺序和有效宽度，补齐高度和样式默认值，移除废弃的入口与阅读卡片配置；主动保存的空布局保持为空，不重建示例卡片。移除与排序不会修改业务数据。

卡片排序柄按用户后续要求从标题左侧移至右上角；左侧保留卡片类型图标，右侧依次为排序、更换样式、移除，工具区预留 90px，切换编辑状态不移动标题。三个按钮均为 26px 方形、6px 圆角，悬浮时使用相同的主题浅色底块、图标高亮及 150ms 过渡；禁用样式按钮仅图标置灰，悬浮底块保持一致且不可点击。拖动与方向键排序继续使用原流程。

编辑模式新增「更换样式」小按钮，复用 `GameOptionsMenu` 的 dashboard 变体。按用户后续要求改成缩略图选择浮层：复用添加目录的 `DashboardPreview` 和真实卡片内容，按当前宽高等比缩小，显示当前分类的可用样式，小图下方显示名称，选中项带边框及勾选。浮层宽 480px、内边距 10px、保留至少 8px 视口边距；该浮层预览高 96px、选项间距 6px，添加目录同为 96px 预览，520px 以下改单列并内部滚动；打开后才挂载预览，内部 inert，整张可用小图均可选择。选择后即时更新草稿，宽高、位置、顺序及业务数据保持；完成保存，取消恢复。待办摘要与日程待办统计的两个入口均提供堆叠图、对比图；切换同步更新原存储类型、标题与内容，不扩展或迁移布局格式。另一种图表已经存在时，以「已在看板中」文字标记并禁用该项，不覆盖邻卡或生成重复卡片；显式移除另一张后可切换。不重新提供已移除的旧摘要与领取进度选项，旧配置可显式切到现有样式；普通模式隐藏入口。浮层支持四个方向键、Home／End 和 Escape，聚焦当前选项或首个可用项，键盘跳过不可用项；选择或 Escape 返回入口，图表类型变化后焦点移至同一位置的新入口。外部点击关闭，靠近视口边缘时避让，外部滚动移动入口时收起。

卡片之间、侧边及下方的整片可见空白也属于画布。按用户确认，拖到鼠标附近的网格位置后保留留白，横向吸附列、纵向按 80px 吸附，遇占用区域向下贴合其底边并保留原间距，不再额外按 80px 向下取整而跳过可用行；首次拖动旧布局时也显示与松手后的卡片同尺寸、同落点的虚线预览框，预览与放置共用吸附及避让计算。拖动中的源卡片将自身收到的拖放事件交给画布，移动后与原范围部分重叠时仍可显示预览并按网格放置；其他卡片的落点调序及原交互保留。首次定位保留其余卡片当前位置；此后保留已保存坐标，缩窗时临时映射列数并避让，回到宽窗恢复。画布覆盖最下方卡片，使用原内容区滚动。旧布局未定位前仍自动排列，拖到原卡片落点调序保留；排序柄方向键调序，Alt＋方向键可移至空白网格。只修改草稿，完成保存坐标、取消恢复，尺寸及样式不变；离开、放置或 Escape 清除提示。

位置为可选字段 `position: { column, top }`，分别按六列坐标与高度步长保存；首次从旧自动布局定位时记录其余卡片现有位置，不强制迁移旧布局。旧上边缩高的 `topOffset` 仍兼容，定位时并入实际顶部距离。定位后的上边缩高仍固定底边，上拉限于画布内可用空位且不覆盖邻卡；下边缩放固定顶边。新增无坐标卡片寻找空位，保存、取消与业务数据边界保持原流程。

空看板按用户后续要求直接留空，不再显示「添加你的第一张卡片」提示卡；页头的「添加卡片」入口及原添加／取消／保存流程保留。

原首页完整事项功能迁到 `src/views/TodoView.tsx`，导航为「小工具 → 日程待办」。事项数据、编辑器、事项库和复盘接口不变；日程待办页移除本周概览，采用 2026-11-14 确认的独立双卡：左侧周导航及所选日程、右侧原未完成待办与事项库，窄容器上下排列。顶栏、灵动岛及系统通知定位新 `todo` 路由；旧带事项 ID 的导航也定位到该页。首页助手为通用看板上下文，旧待办对话仍保留独立会话边界。

统计口径按 2026-11-14 用户确认：待办摘要按计划日期展示含今天的近七个本机自然日，每日一根堆叠柱，绿色为当前已完成、蓝色为待办（包含进行中），合计为当天任务总数；仅统计未删除任务，七天前仍未完成的任务单列「更早待办」。例如计划 11 月 13 日、14 日完成，仍归入 13 日已完成部分；改计划日期后归入新日期，不依赖完成时间是否存在。

新增「日程待办统计」按计划日期展示今天起七天的未完成日程与未完成任务（包含进行中），每天并排两柱，紫色为日程、蓝色为待办；已完成、已删除和窗口外事项不计入。图例显示各类合计，柱上标数，零值保留灰色基线，悬停及无障碍名称提供完整日期和数量。两图共用原共享事项库及页面时钟，完成／重新打开、改期、删除／恢复后同步，跨午夜自动更新日期窗口。

业务数据复用：旧今日安排包含今日与逾期待办、今日未完成日程；旧最近完成仍按真实 `completedAt` 倒序，不用更新时间推算缺失记录。签到使用 `CheckinHomeCard` 与国内版品牌图标；额度只读现有缓存；专注使用原 `island.focus` 和状态广播，切换样式不重置计时。预览只读，不执行签到、项目启停、构建或自动调用模型。
