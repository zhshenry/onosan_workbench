# REL023 · 跨产品共享的待办组件、数据规则与确认流程

适用产品为 ONOSAN，归属首页、日程与待办。[本项进度与任务](../../README.md#首页日程与待办)

## 业务目标

让各应用的待办规则与常用交互能够同步更新，保留各应用的使用入口与外观。

ONOSAN 和 CMO 分机部署，各用本机事项库。同一开发机、同一 Windows 账号运行两个产品时，现有本地路径可供两者共用。抽包的收益是减少重复修改和规则漂移，需结合共享包版本、升级和回归成本评估。

## 验收条件

- 若决定抽包，按分阶段方案核对各接入应用的创建、编辑、确认和日期规则，以及本地已有数据的兼容性。

## 交付进展

待定。迁移提案用于评估工程维护收益，各产品可独立安装和使用。
