# 个人网站内容工作室

采用用户于 2026-11-03 选定的方案 2，并按 2026-11-04 确认的细化稿改为紧凑项目栏与可折叠预览。入口为「网页工作台 → 个人网站」，项目目录为 `C:/Myself/Personal_Website`。本功能编辑本机 Astro 内容项目，应用发版不等于发布个人网站。

## 编辑与保存

- 作品、博客、文库分别读取 `src/content/works`、`blog`、`library` 下的 Markdown，按网站现有字段展示表单和正文。无效文件单独提示，不隐藏其他有效内容。
- 目录顶部「＋」用于新建内容，提供“新建内容”提示与可访问名称。分组使用轻量折叠箭头，空分组不显示零数量，展开后保留空态说明；当前内容使用紧凑的整行浅蓝选中态。
- 新建时校验名称和同名文件；开始编辑仅创建草稿，「保存到项目」才写入 Markdown。正文可提交给现有 AI 助手润色，由用户自行采用建议。
- 保存保留未知 YAML 字段、注释、BOM 与原换行风格；字段序列化可能规范化空格。保存前按原文件摘要检查外部修改，发生冲突时保留草稿，支持查看文件当前内容与拟保存内容。
- 当前草稿暂存在本机，切换内容前确认放弃；重新进入可恢复草稿。原文件读取失败也不自动清除草稿。工作台不提供删除内容操作。
- 封面由原生文件选择器导入，立即复制到 `public/images/workbench`，正文保存后引用；取消正文编辑不会删除已经导入的图片。内容与封面路径均限制在项目内，并拒绝链接／联接目录穿越。

## 开发与检查

- 首次进入启动项目自带的 Astro 开发服务，绑定 `127.0.0.1`。项目缺失或未安装依赖时显示真实错误，可查看日志和使用项目终端处理。
- 保存后由 Astro 开发服务自动更新预览；生产构建由用户在「更多 → 网站检查」抽屉中手动触发，不在每次保存时执行。运行中或失败时，项目栏提供可点击的检查状态。
- 新草稿保存前预览对应栏目；博客保存后按项目 Astro 的文件名转换规则或自定义 `slug` 打开详情，避免未保存详情的 404。
- 项目当前 Astro 不监听启动时为空的内容集合；首次保存该集合内容时，工作台自动重新启动自己管理的开发服务，使新栏目进入预览。后续编辑仍使用热更新。
- 项目栏压成单行，目录路径保留在项目名提示及「打开项目目录」入口。取消工作区页签，默认约 6:4 并列编辑与预览；「正式网页」、设备和展开／收起操作共用一行。
- 桌面使用 1024px 宽的网站视口并缩放至预览栏；手机使用 390×844。「收起预览」释放编辑宽度，「显示预览」恢复；「展开预览」暂时隐藏编辑区，通过「返回编辑」或 Escape 还原。收起和展开均保留草稿、编辑位置和网页会话。
- 工作区不足 900px 时优先展示完整编辑区，使用「显示预览」进入大预览，再返回编辑；保存栏固定，长表单独立滚动。
- 正式网页地址单独配置，本地和正式网页使用不同浏览器会话。切换工作区保留草稿、预览和终端；停止只终止工作台拥有的开发子进程，退出时清理对应服务与终端。
- 构建显示实际退出结果、输出、完成时间并支持取消。页面检查仅验证首页、作品、博客、文库、关于的 HTTP HTML 响应，不代表所有链接、布局或交互通过。
- 保存使既有检查结果失效；检查／构建运行期间再次保存，也不会将旧结果标为当前通过。外部编辑由 Astro 更新，检查结果仍只是显示时间对应的运行结果。
