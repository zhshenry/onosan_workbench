## 五项视觉检查

- 字体：沿用应用现有字体和字阶，标题、字段、说明分级；正文、差异内容可换行。图稿中的字体尺寸不覆盖全应用排版规范。
- 布局：保留目录／编辑／实时预览三栏关系、上方三页签、固定保存栏；窄窗以页签显示预览。较短窗口的 Markdown 正文通过表单内部滚动访问，保存操作不被推走。
- 颜色：雾灰、冷蓝、暖砂三主题均打开实机检查；选择态蓝色、未保存琥珀色、已保存青绿色。服务运行状态额外复核。
- 图片：封面直接读取网站已有 SVG，预览为实际网站，没有用绘制图形替代内容资产。网站原始字号在缩放预览栏内较小，完整预览可放大阅读。
- 文案：使用当前作品的真实标题、简介、封面和正文。源图是未保存状态，基准实机为已保存状态；按钮禁用及状态色差异符合实际状态。既有导航中的规划项、顶栏日程沿用当前应用。
