# Hush-Hour 网页工作区

所属：网页工作台。入口：网页工作台 → Hush-Hour。

- 项目目录：`C:\Myself\vibe_coding\some_idea\cocktail_web`。
- 首次进入时由主进程启动 `http://127.0.0.1:4187/`，只读取项目已有的 `dist/client` 静态构建。
- 项目栏提供「构建并刷新」、本地启动/停止/重启、终端、问题记录，以及打开目录、只读运行说明和构建日志。
- 预览顶部复用游戏工作台的 Segmented 切换「本地预览／正式网页」。正式网页首次选择时才创建，使用独立持久分区 `hush-hour-online`，两边的页面、历史、视口和原生缩放分别保留；普通切换只隐藏网页。
- 正式地址默认使用 2026-10-20 发布配置返回的 `https://hush-hour.onosakayan.chatgpt.site/`，不使用项目里过时的分享地址。复用游戏地址弹窗的网站变体，可校验、保存和清空地址；配置保存在 `websites/hush-hour/settings.json`，重启恢复，取消不写入。
- 正式网页访问不依赖本地服务或有效源码。正式环境下项目栏主按钮显示「构建本地」，完成后只刷新本地预览；当前正式网页及其输入保持。正式网页的刷新、前进/后退、尺寸、缩放、展开、外部打开与截图作用于其当前 guest。
- 构建执行现有 `dev/build-site.mjs`（即项目的 `npm run build:site`），校验三个页面的新产物后刷新当前页面。构建失败/取消保留当前网页，输出可在日志中查看；同一时刻只运行一个受控构建，取消与退出结束其进程树。
- 分别跟踪源码与构建变化：源码变动提示待构建，生成新构建但尚未刷新时提示待刷新；构建期间源码再变动不会被当成已同步。
- 复用游戏工作台预览的后退、前进、刷新、1440×1000 / 390×844 / 跟随窗口、原生缩放、窗口内展开与外部浏览器打开。站点使用独立持久分区 `hush-hour`。
- 项目终端复用现有 PowerShell 面板，默认收起，首次打开才创建独立会话并定位到本项目目录；支持停止命令、清空/复制输出、退出与重连。
- 普通切页隐藏整个宿主，返回时保留同一个网页与当前位置。退出应用关闭本地预览；重启后首次进入重新打开首页。
- 构建缺失或端口被占用时显示真实错误，可重新启动或构建后重试。
- 截图及 `HH-*` 问题独立保存在应用数据目录的 `websites/hush-hour`。问题记录支持必填字段校验、六张 PNG 附件、构建日志快照、历史回看、报告复制与 ZIP 导出；导出不递归收集目录中的其他文件。
- 截图和问题标记本地／正式环境，正式问题仅接受当前配置地址的正式截图，不附带本地构建指纹或日志；更改正式地址后不能把旧地址截图附入新问题，历史快照仍可读取。原有未带环境字段的本地记录按本地环境兼容读取。
- HTTP 服务仅绑定本机回环地址，只接受 GET/HEAD；不允许读取构建目录以外的文件或越界符号链接。启动 IPC 仅接受主窗口主文档。
