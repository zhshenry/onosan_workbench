- 视觉目标：[用户确认的四态稿](design/hush-hour-build-status-approved.png)。这是同一项目栏的四种状态，并非四个页面。

## 五项视觉检查

| 范围 | 结论 |
|---|---|
| 字体 | 继续使用既有 Segoe UI／中文回退字体与共享字阶；项目名、次要路径、状态和行动层级与确认稿一致。未改变全局字号。 |
| 间距与布局 | 项目名旁集中显示状态，失败日志入口同行；四态项目栏高度实测均为 77.48px，下方预览起点保持不变，间隔均为 12px。主按钮最小宽 176px，避免阶段变化挤动其他按钮。1024px 下所有可见操作均在项目栏边界内。 |
| 颜色 | 待构建、构建中、已同步、失败分别使用已有 amber、acc-deep、teal、danger token；徽标文字对比度修复后可辨认。三主题沿用相同结构。高对比模式保留系统前景色，减少动态效果关闭旋转。 |
| 资产 | 使用现有 Phosphor 图标，沿用项目玻璃表面与背景资产；未用合成图片替代可交互界面。 |
| 文案 | 待构建／构建中／已同步／构建失败均来自真实状态，构建失败提供日志与重新构建；没有进度百分比或自动构建开关。外部新构建待刷新、项目读取及启动失败仍保留实际语义与完整详情。 |

确认稿中的“启动本地”按实际服务状态切为启动、重启与停止；预览仍是原有完整预览面板，未改成设计板裁切中的独立小卡。这些属于复用现有产品行为，不是新增界面差异。

## 比较与修订记录

1. 首次对照发现“有更新”徽标沿用主按钮白字，与浅底对比不足（P2）。已改用共享琥珀前景及浅琥珀底。
2. 修订后重新捕获四态，并重新运行九项 Electron 验收。四态的状态、同行日志、按钮层级、间距和文本均可辨认；没有未解决的 P0/P1/P2 发现。
3. 初始验收页遗漏浏览器宿主和共享控件样式，产生了 0px 面板间隔；该轮截图已拒收。补全真实样式后再测，最终三主题均为 12px 间隔。此项是验收页搭建问题，未修改应用公共布局。
