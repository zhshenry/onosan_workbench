# AI 测试工作台

2026-10-21 · 本地实现。入口为一级「AI 测试工作台」，下设对比测试、测试任务和运行记录。采用用户选定的方案 1，总览对比代码与产物，产物详情使用最后确认的大预览稿。

## 使用

1. 在「设置 → AI 助手」配置并启用供应商与模型。测试工作台复用这些连接，不复制密钥。
2. 默认「模型直出」，通过「对比模型」复选菜单选择 1–4 个模型，列表显示模型名及所属供应商。点击「提示词」在弹框编辑 System/User，点击「模型设置」配置温度、单次输出上限、限时及 Agent 工具上限。「应用」更新当前配置，「取消」丢弃弹框修改；执行中可只读查看。材料仍在任务卡添加。默认番茄钟内容是可编辑的任务配置，不含预置模型输出。
3. 可导入 UTF-8 文本文件或 ZIP 起始项目；材料中保留项目相对路径。最多 40 个文件、总计 2 MB；ZIP 不接收 .git、node_modules 或 .env*。模型输出最多 40 个文件、总计 4 MB、单文件 1 MB。
4. 「开始测试」冻结配置并创建新记录，各模型并发执行。单个失败或停止不影响其余模型。「保存任务」保存可再次编辑的配置；结果自动保存。
5. 总览结果的代码默认折叠，点击文件行的「查看代码 / 收起代码」按模型独立切换，预览保留状态。「展开产物」打开内部结果标签，总览保留。相同结果复用标签，切换标签或切走工作台不会重新调用模型。
6. 详情默认为整个内容区的大预览。代码和文件按需查看，可切换代码、分屏、刷新预览和全屏预览。原始文件只读，可导出 ZIP；原始回复和输入快照各有独立内容页。
7. 「复跑本次配置」创建新运行，保留旧结果和断言证据。提示词、材料和参数来自旧快照，供应商连接与密钥使用当前设置；如模型被移除，需重新选择后开始。它不保证随机模型输出一致。

## 两种模式

模型直出只生成一次，不提供模型工具。代码使用带路径的 Markdown 代码块，例如 html:index.html、javascript:src/app.js；支持多文件。未标路径的常见语言代码块按语言提取，纯文字保留原始回复。对同一路径的重复代码块报错，避免静默覆盖。

Agent 执行使用独立的 Pi 会话和产物目录。所有模型获得相同的起始文件、工具定义和执行限额。工具固定为项目文件列出、读取、写入、网页观察、点击/填写、浏览器 JavaScript 和统一断言。Agent 可根据真实工具结果修改文件后再次校验；工具过程及返回结果保存在本次记录。工具上限为 1–40 次，整轮限时 15–600 秒，输出上限 256–16000 tokens 指每次模型回复。超过时间或工具上限结束该模型，已生成内容保留。

当前内置运行环境为 HTML / 浏览器 JavaScript，不安装依赖、不提供系统终端或 Node/Python 执行器。其他语言的代码保留为源码文件供查看、比较和导出，明确显示尚未执行。前端框架项目需要模型交付可直接打开的 HTML/JS；仅交付源码或构建配置不会被标为运行成功。

## 公平性与证据

- 每轮保存实际发送的统一 System/User，包括模式约束和材料文本。流接口显式使用冻结的 System，避免 SDK 自动追加不同临时目录。模型温度、单次输出上限、限时和工具上限来自同一个配置；供应商若拒绝参数，显示其执行失败，不偷偷替换参数。
- 各模型独立运行、失败、停止；文件根目录、网页源与执行分区独立。未启用模型服务或连接被移除时保留输入并提示修正。
- 「已生成」只表示模型结束并留下内容；「可运行 · 网页已加载」表示 HTML 在隔离浏览器完成启动探测，未报告启动错误；功能是否正确由单独的断言说明。探测不证明所有后续交互正确。
- 统一校验使用新浏览器环境，在每项断言前清理本模型的网页存储并重新加载。expression 是返回布尔值的浏览器函数，可为异步函数，只有严格返回 true 通过。可选 setup 在刷新前返回值，设置 reload 后把该值传给断言。
- 校验项在开始前配置，Agent 不能修改它们。修改文件清空旧断言证据。默认五项仅是番茄钟示例，可编辑或清空；未配置、未执行、出错、取消均不显示通过。
- 总耗时包含准备和产物启动探测。tokens 使用供应商返回的用量，不是实际费用估算。受控夹具仅验证工作台链路，不代表实际供应商模型能力。

## 数据与隔离

任务和运行记录存于 userData/ai-tests/ai-tests.db，产物存于同目录的 artifacts/<结果 id>，不读写共享待办库或普通聊天记录。应用退出后，执行中和校验中记录会在下次打开时明确恢复为中断状态。

预览通过专用 ono-ai-test://<结果 id>/… 来源提供，使用 sandbox iframe；启动探测及 Agent 网页工具使用无 preload、无 Node 的独立浏览器分区。禁止外部连接、框架嵌套、权限请求、下载与跨来源导航。原始产物不能获得工作台 IPC。主窗口的手动全屏许可仅限可信主文档，预览子文档不获此权限。

自动验收必须设置 WORKBENCH_TEST_DATA_DIR 和 WORKBENCH_ISOLATED=1，只使用合成模型服务与夹具，不使用个人待办、真实模型密钥或登录分区。源码检查与构建、受控端到端链路、真实模型质量评测分别记录。
