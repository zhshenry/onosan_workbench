# REL016 · 离线语音听写的录音设备选择、识别与文字回填

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../README.md#其他共享能力)

## 业务目标

用户可以在支持的输入框中通过麦克风听写，将识别结果用于当前输入。

## 验收条件

- 选择录音设备并开始、停止听写，核对文字回填，按各产品的安装形态检查资源可用。
