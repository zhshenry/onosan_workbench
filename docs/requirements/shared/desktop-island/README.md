# 桌面灵动岛

2026-11-04：按原讨论最后确认的 V2 方案实施。原顶栏与托盘的悬浮待办入口原位替换为桌面灵动岛；设置位于「通用&外观」之后、「AI 助手」之前。本轮是本地实现，不包含打包发布。

## 交互与数据

### Codex 额度连接恢复（2026-11-09）

常规查询读取现有授权，不强制刷新令牌；由 Codex CLI 管理正常续期。普通 RPC 等待 30 秒，明确授权失败后才额外尝试一次强制刷新，最多等待 60 秒。超时、网络故障或服务暂不可用保留本次运行中上次成功的账户、额度与更新时间，设置显示「更新延迟」，岛内旧额度标注「待更新」，不误报需要安装 CLI 或重新登录。

失败后按 10／30／60 秒退避重试，手动「重试／刷新额度」可立即刷新并合并进行中的查询；正常查询失败不打开登录浏览器。连续两次超时先通过不刷新授权的本机账户读取检查服务，检查仍无响应才重启工作台独立的额度 CLI，不注销账户，也不操作其他 Codex 客户端。明确授权失效时停止自动重试，用户点击「重新登录」才重新授权；主动断开与退出取消重试，旧响应不能恢复已断开的连接。

`island-codex-diagnostics.jsonl` 只记录时间、RPC 方法、耗时、失败类别及数字错误码，约 64 KiB 轮换；不记录账户、令牌、授权地址或原始错误正文。状态由 `electron/island-quotas.ts` 统一提供，设置页与原生灵动岛复用现有状态提示和操作，不新增通知弹窗。回归见 `tests/island-quotas.test.ts`、`tests/island-quota-settings.test.ts`、`tests/desktop-island.test.ts`。

### AI 待办助手（2026-11-08）

采用用户选择的[随身对话窗](design/ai-assistant-approved-2026-11-08.png)，点击任一停靠状态的吉祥物打开一个独立对话窗，取代原来默认打开消息列表的行为。主窗口可保持隐藏，鼠标移出不收起；默认置顶，可独立切换，关闭／Escape 仅隐藏，重开保留输入及同一份对话。顶部展开的吉祥物继续位于左下角。窗口默认为 400×610 逻辑像素，边缘留 12px，按顶部／左侧／右侧向屏幕内展开，小工作区自动约束；可拖动和缩放，重开按岛重新定位。

- 「对话」复用已有待办会话、AI 配置、模型选择、Markdown 回复、澄清提问与停止；首次发送才创建会话。请求范围是待办，不携带岛内文件或其他模块上下文。配置读取失败可重试，无连接可进入既有 AI 设置，开关关闭时可原地启用。模型选择与主窗口共享。
- AI 只能提出修改建议，卡片展示真实目标、全部变更字段及前后值，点击「确认修改」才写入；多项建议沿用逐项选择。取消、关闭、失焦和停止均不自动应用。实际回执显示成功，过期版本或并发手动修改明确报错，不覆盖较新的待办。
- Enter 发送、Shift+Enter 换行，输入法组词不提交；生成中禁止重复发送和切换模型。失败保留问题。输入文字、模型选择与发送／停止按钮共用一个圆角输入框，文字在上，工具栏在框内右下角；模型选择在发送／停止按钮左侧，分别为 26px 高与 28×28px，长模型名称省略，多行文字不与工具栏重叠。滚动阅读历史时不强制回到底部；距离底部至少 64px 时在消息区右下角显示「回到底部」，点击后回到最新消息并恢复跟随，空对话和底部位置隐藏。发送新问题后继续跟随新回复。
- 关闭重开保留首次发送前的输入；已有会话输入延迟保存，应用重启后恢复历史与已保存草稿。首次发送前的草稿不跨完整重启保存。重启使原待确认建议过期，需重新生成，避免直接应用旧快照。
- 「消息」保留原 Agent 未读／全部筛选与查看、标记操作；真实未读数才显示数量。「对话／消息」页签按固定基准等宽，「未读／全部」组固定 160px 并等分；计数和选中态变化不改变按钮坐标、宽高及高亮尺寸，窄窗口才响应式收缩。原日程提醒可跳转工作台查看。打开助手或切换消息页均不自动清未读。消息接入、权限检查去噪与勿扰规则见下方合同。
- 筛选栏右侧提供「全部已读」，批量标记点击时的未读消息，保留历史和原始处理状态；没有未读时禁用。按消息编号及更新时间快照确认，后到消息和更新版本不被旧请求清掉；成功后同步角标和其他窗口。消息写入失败保留未读并可重试，不清除其他类型提醒。

实现归属 `src/views/IslandAssistant.tsx`、`src/views/island-assistant.css`、`electron/desktop-island.ts`，共享 `TodoProposalCard` 仅增加岛内展示变体。新窗口使用隔离 preload、上下文隔离与 sandbox，禁止导航及新开页面；岛接口只放行读取、消息操作、助手控制和已有导航，不允许助手修改岛设置或文件。验收记录见 [AI 待办助手验收](qa-ai-assistant-2026-11-08.md)。

### Agent 对话提醒（2026-11-08）

按确认的[吉祥物消息入口稿](design/agent-mascot-entry-approved-2026-11-08.png)接入 Windows 本机 Codex／Cursor 消息，独立铃铛移除。当前点击吉祥物默认打开待办助手，「消息」页展示「未读／全部」，原事项提醒从同一入口可达。蓝色数字保留未读数，Codex 权限检查不产生待授权数或琥珀点。原稿是放大示意；实际沿用 580×40 顶栏和 224px 紧凑气泡。保留的岛内消息列表使用顶部 580×400 画布（列表宽 432、高 336）或侧边 400×560 画布（侧条宽 64、列表宽 312）。仅列表扩大原生画布，四个原页面尺寸保持。

使用：在「设置 → 桌面灵动岛 → AI 额度 → 账户连接 → Codex／Cursor」单独开启「消息提醒」。Codex 还需要在 Codex 设置 → Hooks 中审核并信任工作台的四项监听（Stop、PermissionRequest、PostToolUse、Interrupt），之后新建会话验证；旧会话未生效时重启客户端。配置存在只表示「监听已配置」，不等于审核或真实消息送达，工作台不自动写入信任记录。审核规则见[官方 Hooks 说明](https://learn.chatgpt.com/docs/hooks#review-and-trust-hooks)。

「提醒」分区原独立 Agent 连接卡片已移除，消息页空态通过「接入与管理消息提醒」定位到新位置，搜索「消息」仍可找到对应来源。额度授权与消息监听状态分别显示，不需要再次登录或新密钥；额度未连接时也可启用本机消息提醒。开启时备份并合并用户级 hooks.json，重复开启不重复注册；关闭只移除本工作台命令，保留其他 Hook 和历史，不注销额度账户。现有监听状态不迁移、不自动修改；普通启动及隔离测试不会自动改真实客户端配置。明确修复真实接入时需分别记录本机收件自检和 Codex 真实回调验收。

- Codex 使用 Stop 提醒本轮回复到达，不把工具执行或权限检查称为会话完成。PermissionRequest 包含自动审核，不能证明正在等待用户，因此不再生成消息；旧中继送入的 approval 及既有此类记录也不显示、不计未读、不触发气泡，原始记录和状态保留。PostToolUse／Interrupt 仅兼容处理旧权限记录。当前 Hook 无法可靠确认真正等待用户，暂不承诺待授权提醒，也不按等待时长推测。按会话／本轮隔离，用 codex://threads/ 链接打开本地原对话。规则修正日期：2026-11-10。
- Cursor 使用 afterAgentResponse 与 stop，呈现回复／运行失败并按 generation 去重；无可靠授权事件时不补造。「打开项目」返回关联目录，「复制会话编号」供在历史中定位，不新建或自动发送提示词。
- 8 秒、关闭、稍后仅收起气泡，不清未读；进入列表也不自动标记。成功打开客户端或显式标记后才记录已读，读取不改变底层权限处理状态。列表不自动到期，关闭后返回伙伴焦点，固定页访问后返回原页。
- 事件只保存来源、会话／本轮编号、项目、短标题、必要说明和状态时间；不读取完整聊天数据库、思考、凭据或终端输出。中继返回空对象，不批准／拒绝操作。通过本机 agent-inbox 原子收取，退出期间继续接收，重启恢复 agent-messages.json；不因日期切换淘汰。非法事件隔离，保存失败保留旧文件和待收事件。
- 隐藏、勿扰、锁屏时只保存消息，不弹 Agent 气泡或系统通知；原日程、健康及额度提醒继续。关闭伙伴装饰时，有消息则保留静态入口。

接口依据：[Codex Hooks](https://learn.chatgpt.com/docs/hooks)、[Codex 会话深链](https://learn.chatgpt.com/docs/reference/commands#deep-links)、[Cursor Hooks](https://cursor.com/docs/hooks)、[Cursor Deeplinks](https://cursor.com/docs/reference/deeplinks)。客户端须支持相应 Hooks。接入文件和合成事件测试不等同于真实云端 Agent 执行或授权成功。

## 久坐提醒（2026-11-07）

按用户批准的[三种停靠确认稿](design/sedentary-approved-2026-11-07.png)加入独立久坐提醒。默认关闭，初始间隔 60 分钟，允许 10–240 分钟整数。专注区及原有待办关联保持；伙伴下方用喝水／久坐两条紧凑行显示名称、间隔、状态和主操作，喝水继续显示今日确认次数。更多菜单复用 GameOptionsMenu 的 island 变体，提供 10 分钟后、今天暂停、提醒设置和关闭，提醒设置直达当前类型的分组。

- 已活动重置完整间隔，10 分钟后延迟当前提醒；今天暂停跨应用重启保留，可主动恢复，次日从新间隔开始。开启、变更间隔和正常重启也从当前时间重新计时。关闭／忽略不记作活动，不新增活动次数。
- 这是定时提醒，不检测坐姿或离座；普通无键盘输入不自动重置。锁屏、睡眠、勿扰时清除久坐旧计时和待处理项，恢复后重新计时，不补弹离线期间的提醒。隐藏灵动岛时仅静默记录，不发系统通知或提示音。
- 同一时刻最多保留一个待处理久坐提醒。喝水与久坐同优先级按创建时间排队，伙伴气泡每次显示一条；已展开／固定时保持当前页。顶部气泡向下、左侧向右、右侧向左；沿用不抢焦点、8 秒闲置收回与伙伴关闭后的普通卡片。
- 外框仍为顶部 580×270、侧边 320×560，页脚固定。280 CSS px 以下提醒内容分行；200px 以下侧边导航保留图标、名称提示与可访问名称。极窄设置卡内说明与控件上下排列，避免单字竖排。
- 旧 desktop-island.json 自动补齐关闭状态及空计时，文件、便签、喝水与专注数据保留。存储使用现有原子写入；失败不替换旧数据，错误可见。

## 设置页

顶部以紧凑单行呈现桌面显示开关、实际状态、停靠位置与边缘间距：图标、名称、状态及位置说明同排，开关靠右；说明在窄容器中省略，悬停可查看全文；设置整理为「显示与交互、页面、提醒、AI 额度、小工具」五个分区。宽容器使用双列紧凑分组，窄容器自动单列，并避开已打开的 AI 助手。页面开关带有图标和说明。

AI 额度采用用户选定的[方案 3](design/quota-master-detail-selected-2026-11-05.png)：同一玻璃表面左侧列出四个来源及真实套餐、连接状态，右侧只显示所选账户的详情；保留必要登录前提、账号、错误和简写更新时间，完整日期可悬停查看。连接／重连／重试位于详情内；已连接 Z Code 默认收起密钥编辑，点击「更新密钥」才打开新密钥字段。「官网」「断开连接」复用共享更多菜单；连接中提供取消授权。「刷新额度」固定在账户连接标题右侧，低额度阈值为下方单行，说明收进信息提示。内容不足 640px 时来源列表改为上方两列，极窄时单列，详情和操作沿内容区滚动；不影响独立灵动岛中的刷新／管理连接位置。

来源列表和详情头使用对应品牌的原始 Logo，保留颜色及比例，本地打包以支持离线展示；[素材来源](../../../../src/assets/quota-providers/README.md)包含官网和原始应用资源路径。功能图标继续复用 Phosphor。

搜索覆盖所有分区与总开关，清空后恢复原分区和所选来源；「管理连接」入口清空搜索并打开 AI 额度。开关和数值即时保存，失败保留已提交值并显示错误，非法数值不写入；低额度阈值仍为 0–50，失焦保存，0 关闭提醒。密钥不回填已保存值，草稿仅在当前设置组件会话保留，切换来源、分区或搜索不丢失；这些切换会恢复掩码。连接失败保留输入以便重试，成功或取消编辑后清空；异步请求完成不会切回旧来源，处理中禁止重复提交。清空文件引用需行内确认，取消不改变记录。显示器和停靠位置复用共享 Select，分区和时段分别复用 Segmented、TimePicker。

## 额度展示

收起摘要与展开额度页复用同心环：外圈优先 5h、内圈优先周额度，彩色弧长表示剩余比例，悬停可查看具体周期和百分比。收起摘要常驻展示 Codex／Z Code／Cursor／Grok Bot 四家，分别使用紫／绿／蓝／橙色；名称旁显示额度环，未连接、加载和失败状态放在名称下方，左右侧栏纵向排列。顶部使用 26px 小环，窄容器使用 18px 小环；左右侧栏常规额度环与伙伴为 24px、日历图标为 20px，伙伴和日历靠上固定，额度组在分割线下的剩余区域独立居中；紧凑高度下恢复 18px 额度环和较小入口，保留全部状态与提醒。单个真实周期只显示单环，未知周期保留服务名称，不补造 5h／周。未连接时为灰色轨道，0% 没有彩色圆点。展开页复用 Segmented 切换 Codex／Z Code／Cursor／Grok Bot，默认展示已有额度数据的来源；左侧环形，右侧周期、剩余百分比和重置时间，两个常见周期在 580×270 下无需滚动。更多周期保留在右侧列表中，环形概览最多两圈。过期或查询失败保留最近数值并显示「待更新」和具体状态；刷新与管理连接沿用已有接口，依次常驻右下角；已连接、未连接、加载和失败状态下位置一致，内容及错误提示在上方独立滚动。

2026-11-07 额度页压缩布局：顶部环 96px，侧边环 112px；侧边概览内距 4px、分区间距 12px、详情／周期间距 8px。常规双周期及断线说明无需滚动，侧边三周期样例同屏可见；更多周期与放大时保留真实滚动，刷新、管理连接不随内容滚动。极窄时状态和操作分行、重置时间占完整行，避免将百分比或日期裁掉。未改变额度查询、来源选择、状态或真实数据，见[布局验收](qa-quota-no-scroll-2026-11-07.md)。

## 额度连接

Z Code 的周期除 `windowDurationMins` 外，也读取 `unit + number`：`unit=3` 表示小时，`unit=6` 表示周；例如 `3×5` 显示 5h，`6×1` 显示周。`CREDIT_LIMIT` 的周期未知时显示积分配额，不凭数组位置猜测周期。百分比仍按接口已用比例换算为剩余比例。

- Codex：用户点击「连接账户」后，通过本机 Codex CLI app-server 登录 ChatGPT；Windows 优先查找 PATH 中的原生程序，也识别标准独立安装目录、npm 安装的原生程序和 Codex 桌面版附带的 CLI，以绝对路径启动，避免安装版依赖开发终端临时 PATH。使用独立 `island-codex` 目录与系统 keyring，不读取其他客户端登录文件。只调用初始化、账户登录／读取／退出和 rate limits 接口，不发起模型任务。
- Z Code / GLM Coding Plan：用户主动输入个人套餐 API Key，以 Electron safeStorage 加密后本机保存，固定调用官方额度查询端点。密钥不写入渲染状态、日志或测试截图。
- Cursor：使用系统默认浏览器完成 Cursor 账号授权，避免内嵌窗口的人机验证兼容问题。采用 Cursor 客户端的 `loginDeepControl` 一次性随机标识与 SHA-256 proof key，工作台经 `api2.cursor.sh/auth/poll` 接收本次结果；不启动模型任务。仅将本次签发的有效会话存入自己的 `persist:island-quota-cursor` Chromium Cookie 存储（Secure、HttpOnly、真实过期时间）。通过网站的 `GET /api/usage-summary` 读取 Cursor 模型与其他模型池的真实百分比，缺少分池时使用返回的总额度；仅在返回 `billingCycleEnd` 时显示重置时间。
- Grok Bot：使用同样的系统浏览器流程，登录 Bot 绑定的 Cursor 账号；本次会话独立保存在 `persist:island-quota-grokbot`。通过 `POST /api/dashboard/get-sand-usage-status` 读取 `usagePercent` 与 `nextResetTimestampUtc`。没有个人配额或使用团队共享池时明确说明，不显示假百分比。两个来源可能共享套餐用量，分别展示返回值，不合计。
- 两个新增连接只使用工作台自己发起的授权，不读取 Cursor 数据库、Grok Bot 凭据或其他浏览器登录；配置 JSON 仅保存连接开关，渲染状态不包含 token、proof key 或 Cookie。等待授权时可取消，5 分钟未完成提示超时；404 继续等待，临时网络故障重试，429 退避，拒绝或无效结果明确提示。取消、重试或退出使旧结果失效，断开只清理本来源的会话，不影响另一个来源。网站内部接口并非公开稳定 API，变更或失败时显示明确状态并保留最后成功快照。依据：[Cursor 浏览器授权](https://prod.cursor.com/docs/cli/reference/authentication)、[Grok Bot 登录说明](https://docs.x.ai/grok-bot/faq)、[Cursor 用量说明](https://prod.cursor.com/help/models-and-usage/usage-limits)；授权协议对照本机 Cursor 客户端，Cookie 与字段映射参考 [Pulse 授权实现](https://github.com/qunqin24/Pulse/blob/main/Sources/Pulse/Auth/CursorWebLogin.swift)、[grokbot-usage-cli 源码](https://github.com/bcharleson/grokbot-usage-cli/blob/main/cli/grokbot_usage.py)。
- 刷新至少间隔 60 秒，后台通常 5 分钟；429 按 Retry-After 退避。失败保留本次会话最后成功值与更新时间，明确标记待更新；未连接、无指标时不造百分比。周期、剩余比例和重置时间只从响应中可支持的字段生成，不把未知周期硬编码成 5 小时或周。
- 低额度默认阈值 10%，0 为关闭；低于阈值时按账户散列、窗口和重置时间去重，并跨重启保留最近 200 个周期标识。服务未提供重置时间时不会猜测新周期。
- 断开仅操作灵动岛自己持有的连接，不退出其他客户端。官网的安全验证、SSO 与 MFA 需要用户在系统浏览器完成；真实账户授权和额度在线响应仍需用户在设置中连接后验收。2026-11-05 已通过隔离 Electron 中的浏览器交接、等待／取消、合成授权结果、Cookie 持久化与重启检查，并实测官方等待端点返回 404；未代替用户完成人机验证。

协议依据：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[GLM Coding Plan 官方用量查询](https://docs.bigmodel.cn/cn/coding-plan/extension/usage-query-plugin)、[官方查询脚本](https://github.com/zai-org/zai-coding-plugins/blob/main/plugins/glm-plan-usage/skills/usage-query-skill/scripts/query-usage.mjs)。Windows 全屏检查只读窗口几何，使用 [SetThreadDpiAwarenessContext](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setthreaddpiawarenesscontext) 对齐 DPI 坐标；后台助手不读取窗口标题、按键或画面。

## 实现归属与持久化

- `electron/desktop-island.ts`：窗口、IPC、提醒投递和系统生命周期；`island-fullscreen.ts`：Windows 全屏检测。
- `electron/island-file-icons.ts`：Windows 通过隐藏的只读助手批量调用 [SHGetFileInfoW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow)，保留文件夹、快捷方式及自定义图标；文件路径通过 UTF-8 JSON 标准输入传递。当前暂存列表共用一次图标读取，增加／移除／重定位后失效；图标不持久化，失败时保留文件名和操作并显示文件类型占位。其他系统沿用 Electron 的关联图标。
- `electron/island-store.ts`：`desktop-island.json` 的设置、文件引用、文字记录与草稿、计时、当日提醒和额度去重记录。文字新增、更新、删除和草稿写入只接受主工作台或本岛主文档，使用原有原子写入；失败不替换内存状态，旧 JSON 默认空文字与草稿。定时完成与入队一起写入；损坏状态文件保持原样并报告错误，主工作台与系统提醒继续可用。
- `electron/island-quotas.ts`：连接与查询；`island-connections.json` 仅保存 Codex 连接开关与 Z Code 密文。
- `shared/island-contracts.ts`、`shared/island-quota.ts`：契约、屏幕尺寸、计时和供应商响应映射。
- `src/views/DesktopIsland.tsx`、`desktop-island.css`：独立窗口；`IslandShelf.tsx`：应用文件与文字编辑；`IslandSettings.tsx`、`island-settings.css`：共享设置页。
