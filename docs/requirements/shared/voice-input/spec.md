# 内置离线语音听写

## 范围

AI 侧栏听写入口位于模型选择右侧、发送左侧。点击后准备内置引擎和麦克风并开始录音；停止后在本地转写，预览文字可编辑，再主动插入草稿。听写绝不触发聊天发送。AI 输入框是否可用仍遵守既有模型配置规则，本地识别本身不需要模型 API Key。

不增加实时字幕、语音对话、自动润色、系统全局听写或录音历史。

## 已选视觉

2026-10-19 用户接受方案 2 的扁平细化稿。保留圆形麦克风标识、语音听写标题、本地标记、设置、两个下拉框、浅蓝音量区与取消/停止按钮。通过收紧留白、缩短波形区控制高度，不能改成删去标题与下拉框的极简条。

卡片使用原生非模态 popover，宽度跟随输入框且不超过 432px，底边位于输入框上方 8px；不占布局高度，不移动消息与草稿。录音态约 174px 高，错误和结果允许自然增高并受视口约束。字体、颜色、形状、焦点与滚动均使用既有 token 和共享控件。波形显示真实输入音量，不是模拟字幕或随机动效。

实现归属：src/views/SpeechInput.tsx、speech.css、共享 src/ui/controls.tsx 的 Select/Modal；样式在应用入口统一加载。

## 录音与草稿

- 单次最长 120 秒，达到上限自动停止并转写。
- 浏览器录音后转换为单声道 16kHz PCM16 WAV，最大 4MiB；主进程和识别进程都检查格式、大小和时长。
- 开始时捕获会话、草稿版本与选择范围。确认插入时，同版本只替换该选择范围；草稿已改动则明确显示追加，并保留现有文字。
- 切换会话、关闭侧栏、隐藏窗口、录音/转写期间失去窗口焦点或按 Escape 会取消，旧结果不能写入新对话。下拉菜单和模态设置的 Escape 先由各自控件处理。
- 停止、取消、设备断开和准备失败都关闭音轨；准备期间取消后才得到的麦克风授权也必须立即释放。
- 设备及语言偏好存入应用自己的本地界面存储；录音时的选择固定，本次录音中修改设置只影响下次。
- 音频仅在内存中处理，不写文件、不上传；确认后的文字沿用原有草稿持久化，主动发送才进入既有聊天链路。
- 卡片存在期间先完成插入或取消，再切换对话模型或发送；草稿仍可编辑。确认插入后切换模型保留草稿，不混淆聊天模型与本地识别引擎。

## 引擎与权限

采用固定的 sherpa-onnx-node@1.13.8，使用 CPU 两线程、SenseVoiceSmall INT8 与 Silero VAD；识别在独立 Electron utilityProcess 中运行，不在渲染器或主进程执行原生推理，不启动 HTTP 服务。

同一时间只有一个录音租约/推理任务。取消主动终止子进程；引擎准备上限 60 秒，转写上限 120 秒；空闲五分钟释放。退出应用关闭子进程。结果按任务编号匹配，旧进程的退出和超时不能终止新进程。

IPC 只允许可信主窗口的主框架，参数不可提供任意模型路径或进程选项。麦克风权限只允许该主文档的音频请求，拒绝摄像头、混合音视频、其他窗口和子框架；内置网页分区的既有拒绝策略保持独立。

## 安装与构建

资源清单 assets/speech/manifest.json 固定三份资源的版本、字节数、SHA-256 和上游 URL。npm run prepare:speech 下载并校验至被 Git 忽略的 vendor/speech/。构建会检查资源；首次构建需要下载，安装后的用户不需要下载。

electron-builder 将该目录完整复制到 resources/speech/；原生 JS、NODE 和 DLL 来自生产依赖，独立 worker 由 tooling/build.mjs 打包。运行时只使用自身安装目录，资源缺失或校验失败提示修复安装，不自动改为云端识别。

模型和词表合计约 230.2MiB，Windows 原生库约 22.4MiB，均为解压后体积；不能作为安装包压缩增量或内存用量的承诺。

assets/speech/licenses/ 随包保留 DeepSeek MIT、sherpa Apache-2.0、Silero MIT、ONNX Runtime MIT 与第三方声明，以及 SenseVoice 独立模型协议、原模型名称、作者、转换来源和固定版本引用。模型权重协议不由源代码 MIT 代替。

## 验收

在隔离数据与虚拟麦克风下，验证真实录音/转换/原生识别/预览/插入、草稿更改、切换对话、取消、拒绝权限、三主题与 1024×680。另从打包后可执行文件重复关键流程并校验内置资源。虚拟输入和公开测试音频不等于真实房间噪声、方言准确率或全新 Windows 环境验收。
