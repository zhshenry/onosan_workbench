# REL015 · AI 连续任务的进度胶囊、停止与恢复

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../README.md#其他共享能力)

## 业务目标

让用户从界面看到 Bot 工作进度，并在相应状态下继续或停止任务。

## 验收条件

- 分别操作进行中、失败和停止的任务，检查活动入口显示的状态及后续动作。

## 交付进展

活动、失败、停止与恢复 · 2/2 项
