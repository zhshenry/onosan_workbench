# AI 供应商页内配置验收 · 2026-11-05

采用用户选择的方案 1，并落实两项修订：左侧目录完全来自用户添加的供应商，不创建内置条目；决策模型（RLCD）与对话模型使用相同的双栏布局、连接表单和模型列表。目标稿为[双栏直编修订稿](design/provider-inline-approved-2026-11-05.png)，设计稿按仓库既有规则仅保存在本机。

## 实现范围

- 左侧显示供应商名称、通用连接图标和实际模型数；空配置显示添加引导。
- 右侧可编辑 Base URL、API 格式与 API Key，点击「保存配置」后生效；无改动时禁用保存。复用原保存接口、Select、IconButton 和 Modal。
- 供应商编辑与删除、模型删除使用既有更多菜单；连接测试、模型编辑、图片输入设置和删除确认保留。RLCD 不显示当前对话模型标记或图片输入开关。
- 草稿按类型和供应商 ID 隔离，切换、搜索、折叠或切页后在本次渲染器运行中保留；新输入密钥不写入浏览器存储，重新加载渲染器后不恢复。成功保存清空密钥输入并重新遮罩；留空保留原密钥，移除需显式选择后保存。
- 保留单行启用栏、两块背景卡片和问号说明；不恢复全局成功提示与隐私页脚。

代码归属：`src/views/AiSettings.tsx`、`src/shell.css`；行为与视觉同步记录于根目录 `UX-CONTRACT.md`、`DESIGN.md`。
