# REL008 · Bot 对话中的操作确认、补充提问与执行结果卡片

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../../README.md#bot-与-ai-工作区)

## 业务目标

在主对话以同一种卡片呈现执行结果和操作请求，以业务对象、状态及下一步为主要内容。

## 验收条件

- 在并排和悬浮对话分别验证成功结果与待确认请求，卡片能显示状态并承接对应操作。
