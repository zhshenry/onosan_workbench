# REL004 · Bot 持续会话、任务委派、原地确认与跨端同步

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../../README.md#bot-与-ai-工作区)

## 业务目标

每个 Bot 有一条持续主对话。同一件事可以在这条对话中补充、确认、委派或续做，双方都能追踪结果。历史消息在原对话中分页查看和收起。

## 验收条件

- 发送补充后原任务收到更新，确认结果和委派回执回到当前对话，重开能查到已保存的记录。
