# REL001 · 常驻 AI 助手的工作台入口、主对话与模型配置

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../../README.md#bot-与-ai-工作区)

## 业务目标

让用户在各工作台直接打开对应的助手，并从工作台内的主对话持续处理当前事情。

## 验收条件

- 从两个工作台分别进入助手，切回原工作台后能继续对应的主对话。

## 交付进展
