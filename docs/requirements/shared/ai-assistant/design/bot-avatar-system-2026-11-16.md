# Bot 头像系统

日期：2026-11-16。实施更新：2026-11-17，已按本方案接入 SVG 头像、形状／颜色选择和旧值兼容。导航悬停、选中外框及右键资料交互保持原样；第 9 节未确认的动效不实施。

确认记录（2026-11-16，用户在评审表单中逐项选择）：

1. 头像拆成「头像」和「颜色」两个独立选择，参考 Grok Bot、ChatGPT Dots 的形状与颜色分开选。
2. 角色的脸用「竖眼直接画在身体上」，不用深色面屏。
3. 两类头像都保留：角色是默认，不拟人的图形在编辑弹窗里用「角色 / 图形」切换。
4. 图形底色全局固定为浅底，不提供实底，也不放进设置。
5. 先把定稿写进设计文档，代码之后再改。

## 1 结论

- 每个 Bot 的头像由一个头像和一种颜色组成。头像分「角色」「图形」两类，各 12 个；颜色 10 种，两类共用。
- 角色：柔和的几何身体加 OnO 吉祥物的竖眼，带轻微立体高光。圆环留给总管 OnO。
- 图形：由一到三个基本几何形组成的双色标志，放在统一的浅色圆角底板上，不画脸，也不画具体物件。
- 每个 Bot 各自选择，导航里允许角色和图形混排；默认全部是角色。
- 两类都用矢量绘制，颜色只是参数，替换现有的 3D 贴图雪碧图。
- 头像颜色属于身份，不随 8 个主题、导航样式或玻璃材质变化，和品牌图标一样保持稳定。

## 2 参考与取舍

| 参考 | 做法 | 本方案取用 |
| --- | --- | --- |
| Grok Bot | 默认头像是彩色几何形加两只竖眼；编辑器的「Bot」页签分别选形状和色板，另有生成、上传页签；Bot 颜色可以染到 1:1 对话 | 形状与颜色两轴分开；竖眼作为统一的脸；编辑器分页 |
| ChatGPT Dots | 形状、颜色、眼睛、眼镜、配饰都能单独换，是 3D 角色 | 属性拆开选；首期不做眼睛和配饰，避免选项过多 |
| Claude Duet | 未见头像编辑器，界面极简，不做拟人化形象 | 图形类不画脸；角色也不加嘴、腮红和配饰 |
| iOS 快捷指令、Linear | 图标和颜色分开挑，图标落在统一底板上 | 图形类的统一圆角底板 |
| 现有 OnO 头像 | 7 张 3D 贴图，颜色和图案绑死；`violet`/`purple`、`blue`/`sky` 两组很难区分 | 圆环留给总管，各 Bot 的默认颜色大体沿用 |

外部产品的做法来自 2026 年 11 月的公开文档和评测，没有在本机实际使用这些产品核对。

## 3 角色（12 个）

| id | 名称 | 说明 |
| --- | --- | --- |
| `ring` | 圆环 | OnO 吉祥物本体，总管默认 |
| `orb` | 团子 | 最中性的基础形，也是未知值的回退 |
| `square` | 方糖 | 规整，像一页日历 |
| `drop` | 水滴 | 一滴墨 |
| `sail` | 小帆 | 圆角三角，像一面帆 |
| `hex` | 蜂巢 | 实验、测试 |
| `cloud` | 云朵 | 轻松，适合陪伴 |
| `flower` | 花瓣 | 也像一枚齿轮 |
| `ghost` | 幽灵 | 游戏里的老朋友 |
| `pill` | 胶囊 | 横向，最稳重 |
| `star` | 星星 | 收藏、评分 |
| `bear` | 小熊 | 角色感最强 |

绘制规则：

- 在 100 × 100 画布内绘制，按视觉面积而不是外框对齐大小；所有尖角圆化（多边形用同色、圆角连接的描边）。背景透明，不用圆角矩形裁切。
- 身体用径向渐变：亮部 → 主色（48%）→ 暗部；左上叠一枚白色高光椭圆，不透明度 0.42，裁切在身体内。
- 眼睛沿用顶栏 OnO 吉祥物的竖向胶囊眼。常规宽 10.5、高 21、两眼中心距 22；圆环和星星用宽 9、高 18、中心距 18。眼睛放在各形状的视觉重心，水平居中，颜色取该色的「深色」值。
- 头像不小于 40px 时，每只眼睛加一个白色眼神光（半径 1.8，不透明度 0.85）；石墨的眼睛本身是浅色，不加。
- 圆环中心是浅色内芯（该色的「浅底」值）配深色眼；石墨圆环改为深色内芯 `#15181D` 配白眼，避免眼睛和内芯同色。
- 评估过「深色面屏 + 白眼」的机器人脸，用户没有采用。

## 4 图形（12 个）

| id | 名称 | 暗示 |
| --- | --- | --- |
| `orbit` | 轨道 | OnO 圆环的平面版 |
| `grid` | 方格 | 一格格日程 |
| `waves` | 波纹 | 一行行文字 |
| `plus` | 方向键 | 游戏手柄的十字键 |
| `sails` | 双帆 | 一艘小船 |
| `half` | 对半 | A/B 对比 |
| `gear` | 齿轮 | 工具 |
| `hexdot` | 六角 | 实验格 |
| `moon` | 新月 | 安静、阅读 |
| `stack` | 叠层 | 文档、素材 |
| `arch` | 拱门 | 入口、网页 |
| `diamond` | 菱形 | 通用 |

绘制规则：

- 底板是铺满头像框的圆角方形（超椭圆），填充该色的「浅底」值，再描一圈 2 单位、不透明度 0.16 的暗部细边。
- 图形用两种墨色：主体用暗部，辅助用主色；石墨的主色太深，辅助改用亮部。需要断开的地方用底板色留缝。
- 只暗示用途，不画具体物件，也不使用 Phosphor 功能图标，避免和导航、按钮图标混淆。
- 新增图形前，先检查它会不会被看成常见界面符号（添加、刷新、禁止、关闭、菜单、更多、加载）。本轮已经按此修正三处：十字加了中心孔，不像「添加」；圆环不断开，在 24px 时不像「刷新」；对半改成竖切，不像「禁止」。
- 评估过「实底 + 白色图形」：混排时实底色块比角色更抢眼，用户选择全局固定浅底。

## 7 编辑弹窗

在主窗口的 Bot 资料侧栏，点击顶部头像打开浮层。鼠标悬停、键盘聚焦或浮层打开时，头像中央显示编辑笔。浮层贴在头像下方，左右边缘收在侧栏内，高度不足时可在浮层内滚动。

1. 顶栏左侧切换「角色 / 图形」，右侧的「重置」将这个 Bot 的默认造型和颜色放入草稿。
2. 每类 12 个头像，每行 5 个，末行居中。下方是 10 个圆形色块，头像和色块均以细环标出当前选择。上方的大头像同步预览。
3. 点击外部或按 Esc 收起浮层并保留草稿，Esc 将焦点送回头像。浮层内可直接「保存修改」或「取消修改」，与名称、简介共用资料草稿。

- 切换「角色 / 图形」时保留当前颜色。弹窗打开期间，两个分页各自记住选到哪里；第一次切到另一类时，从该 Bot 的推荐默认开始（见第 6 节）。
- 保存时只写当前分页的结果，不额外记住另一类上次选了什么；下次打开弹窗再切换，仍从推荐默认开始。
- 头像改动参与「有未保存修改」的判断，沿用现有的关闭保护和版本冲突流程。
- 分段切换、头像选项、颜色都按原生单选组处理：Tab 进入组，方向键切换，有可见焦点。可访问名称写成「角色：水滴」「图形：波纹」「颜色：石墨」。
- 不提供上传、生成和配饰。

## 9 执行动效（用户已确认，2026-11-17）

侧栏头像动效（2026-11-17 用户追加：参考 DS-Bot，增大幅度）：思考时侧头眯眼，搜索／读取时扫视，执行时轻跳或按角色形状扭动／压缩拉伸，交接时侧移，回复时点头。42px 头像的主要跳动约 3–5px，倾斜 8–12°；具体关键帧统一由 src/views/bot.css 持有。等待其他 Bot 时以 3.2 秒周期小幅慢摆（左右 3°），显示空心状态点及“等待协作结果”；等待用户／资源或执行中断时仅提醒一次，结束后完全静止并保留问号角标；任务真实成功后回弹 1.1 秒，失败、取消、历史数据加载不播放成功回弹。选中态与执行态独立，后台执行者继续显示自己的状态。

空闲与排队默认完全静止，不自动眨眼、歪头或舒展。鼠标进入时播放一次 600ms 的表情反馈，点击或键盘激活反馈 480ms，之后归位；鼠标留在入口内移动不持续跟随，也不重复触发。持续动作只用于真实执行或协作等待；执行时头像右下角保留实心状态点，协作等待为空心点，展开侧栏的第二行显示真实活动，静止或减少动态效果时仍能识别。空闲第二行恢复原职责；选中底色只表达当前查看对象。原切页及右键资料行为不变。只在侧栏启用，历史消息、资料和选择器静止。沿用 42px 头像、54px 点击框及现有两态坐标；不缩放导航框。页面隐藏或头像离屏暂停；30 秒无输入暂停循环，有输入恢复，有限次提醒／成功反馈不受休息计时影响，固定状态点和状态文字不因暂停而消失。系统减少动态效果取消全部动画和倾斜，悬停提示及可访问名称继续表达真实状态。图形头像沿用身体动作，不添加眼睛。

- 思考周期 1.9 秒、搜索身体 1.3 秒／眼神 1.5 秒、执行 1.25 秒、交接 1.1 秒、回复 1.5 秒、协作等待 3.2 秒。提醒和成功均为 1.1 秒 × 1 次、悬停反馈 600ms、点击反馈 480ms；只有执行／协作等待周期性眨眼（4.7 秒），按身份错开起始时刻。空闲与排队没有循环动作。上述身体位移以 100×100 SVG 坐标缩放到 42px，页面坐标及点击框不动。
- BotAvatar 的 activity 默认不传（静态）；只有侧栏传入真实活动、身份和成功标记。src/bot-avatar-motion.ts 共用一个 30 秒活动时钟，每个可见头像通过 IntersectionObserver 管理暂停；悬停以 pointerenter 触发一次反馈，不监听入口内鼠标位移，也不逐帧触发 React 渲染。减少动态效果优先于全部 hover 与分形状样式。
- ONO 通过 BotCard.activity 接入真实流式思考、工具和回复事件，状态变化才发送 activity 通知；短暂工具阶段不人为延长。运行活动保存在 Host 内存，不改任务 revision／时间戳。仍有运行任务时优先展示执行阶段，等待确认数量独立保留；全部停下后按用户等待、资源等待、协作等待、排队、中断确定表情。completion 仅标记真实成功，首次加载和重复刷新不回弹。后台兼容版本 v6 在空闲时接替 v1–v5，旧任务运行时沿用保护；开发态需要完整重启 npm run dev。
- 参考 DS-Bot 的[状态映射](https://github.com/Fei2411/DS-Bot/blob/main/ds-bot/src/client/mark.js#L14)、[动作分层](https://github.com/Fei2411/DS-Bot/blob/main/ds-bot/src/client/styles.js#L30)及[30 秒休息](https://github.com/Fei2411/DS-Bot/blob/main/ds-bot/src/client/motion-rest.js#L9)；ONO 继续使用自身 SVG、任务数据和 CSS，不引入角色素材或动画依赖。本版没有增加动效档位设置，也不让全页头像追随鼠标。

## 10 实施要点（已实施，2026-11-17）

`shared/bot-avatar.ts` 维护形状、色板、推荐值和旧值解析，`src/views/bot-avatar-art.ts` 使用第 11 节的矢量数据，`BotAvatarPicker.tsx` 负责选择。旧头像在读取时归一化，不批量改写资料或增加 revision；保存资料时写入规范值。为避免已运行的旧 Host 拒绝新头像字符串，后台兼容版本更新为 `bot-workbench/v3`，沿用既有的空闲升级保护接替 v1／v2；有在跑的任务时不强制替换。接口字段和数据库结构未变，开发态需完整重启一次。

隔离 Electron 已验证经典／悬浮导航两态、240 种组合、8 个主题、灵动岛、100%／200% 显示比例、键盘选择、取消／保存／重开、未保存关闭保护及强制颜色模式。记录见 [设计验收](../../../../../design-qa.md)。

- **数据**：`BotProfile.avatar` 仍是一个字符串，写成 `<头像 id>:<颜色 id>`。两类 id 不重名，按 id 判断类别；接口、存储结构和 revision 都不变。`shared/bot-contracts.ts` 的种子值改为第 6 节的默认值，读取旧资料时按第 6 节迁移。
- **渲染**：新的 SVG 头像组件替换 `src/views/BotAvatar.tsx` 的雪碧图裁切和 `src/assets/bot-avatars.png`，所有尺寸共用一个组件；几何和颜色以第 5、11 节为准。`forced-colors` 下保持头像原色（`forced-color-adjust: none`），由旁边的名字承担识别。
- **编辑弹窗**：`src/views/BotProfile.tsx` 的头像一行按第 7 节拆开，样式放在 `src/views/bot.css`，复用现有字阶、控件和颜色 token。
- **验收**：7 个默认 Bot 在经典和悬浮导航、展开和收起、8 个主题、深色灵动岛，以及 27–58px 各个尺寸都能分辨；逐项核对旧值迁移、未知值回退、切换类别保留颜色、未保存提醒和键盘操作。实施完成后再同步 [DESIGN.md](../../../../../DESIGN.md) 和 [UX-CONTRACT.md](../../../../../UX-CONTRACT.md)。
