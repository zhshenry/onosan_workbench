# REL007 · 总管与用户接续编辑右侧看板卡片

适用产品为 ONOSAN，归属跨工作台能力。[本项进度与任务](../../../README.md#bot-与-ai-工作区)

## 业务目标

总管和用户可以交替操作同一张看板卡片，共享已保存的布局和卡片状态。

## 验收条件

- 用户移动并保存卡片，总管改同一张卡的样式，用户调尺寸后总管能读回新值。

## 交付进展

看板本地人机接续 · 2/2 项
