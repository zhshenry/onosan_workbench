## 真实页面覆盖

- AX 观察、中文输入、已有字段的重复替换与清空、多行/富文本替换、可信点击、按标签/值选择下拉项、勾选状态、空格键切换。重复 AI 填写同时检查实际字段值，不能只复用此前的成功提示。
- 封闭 Shadow DOM、同进程及跨进程 iframe 元素点击；元素改名或状态改变后拒绝旧引用。
- Chromium 沙箱开启、guest DevTools 界面禁用时，仍可连接并完成实际输入。
- 普通和封闭 Shadow DOM 密码不出现在元素值中；通用输入拒绝当前敏感或无法确认的焦点。
- 截图实际像素与 CSS 元数据一致；坐标点画布、125% 页面缩放、拖动、滚动。
- 遮挡、旧元素引用、旧截图和整页截图误用于坐标输入会拒绝执行。
- 实际 PI 循环运行六个浏览器工具，读到真实页面变化后检查条件。
- 弹窗加入任务、跨站等待可见授权、显式标签打开/选择/关闭；关闭后回到剩余任务标签。
- 右侧现有 AI 对话直接操作当前标签，无独立目标表单；空标签可经站点授权后打开用户指定网页。
- 切工作台及收起助手后原 guest 继续实际填写和点击，宿主焦点仍在首页；隐藏整个应用窗口后任务仍完成，不显示或聚焦窗口。
- 暂停和取消，迟到模型回复不会重新开始操作。
- 同一未验证任务在原对话澄清后继续；已完成任务再次发送时重新绑定活动标签。
- 没有独立目标输入、标注或开发诊断入口；相关后端/API 同步移除。模型列表在编辑按钮旁显示「多模态」眼睛切换按钮，睁眼/划线眼睛对应开启/关闭，点击即时保存，键盘可切换；普通编辑模型不重置图片能力，正常重启后保留；历史与弹层 Escape 可用。
- mist/cool/warm × 1280×820、1024×680；记录实际窗口/CSS/DPR；AI 助手展开时浏览器按钮通过真实命中检查。
- 正常退出重启恢复标签与持久 Cookie；清理当前站点不清理同分区的其他测试站点或小红书分区。
- 新增 role/name、label、placeholder、testId、CSS、text、容器链、and/or/has/hasNot、可见性、nth 定位；两个同名按钮只操作指定容器内目标，跨进程 frame 与封闭 Shadow DOM 可定向读取。
- 320 个按钮中偏移 300 的分页与从零计数第 319 个元素可达；2 万字正文可从第 14000 字之后分段读取；nth 同时限定正文。

- 地址栏建议在真实 guest 上方可命中、方向键与回车打开对应历史；历史检索、时间过滤、单条删除、数据类型选择可操作；带业务参数/锚点的地址重启后保留。
- 助手不额外显示网页关联提示行；固定文章 A、切至干扰文章 B、进入“我的小红书”后，原对话同时获得 A 的真实正文和网页工具，经定位器实际填写标题/正文并核验；A/B 本地内容不被覆盖，返回编辑页保留固定 A。小红书域名内容由隔离分区的本地协议夹具提供，不访问真实平台或账号。
