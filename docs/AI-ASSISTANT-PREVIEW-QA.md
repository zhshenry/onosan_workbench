## 2. 实际浏览器检查

使用 Codex 内置浏览器访问本机静态页面，通过真实按钮、输入框和选择器操作；截图为实际页面捕获。

| 检查 | 结果 |
|---|---|
| 博客建议应用 | 点击“应用到正文”，开头替换为建议内容，卡片显示已应用 |
| 博客撤销 | 点击撤销，恢复原开头 |
| 内容版本变化 | 先编辑标题再应用旧建议，出现“原内容已经变化，请根据最新内容重新生成” |
| 跨页草稿 | 博客输入未发送文本，切到首页再返回，输入原样保留 |
| 不同文章 | 切到其他文章出现其独立会话，返回恢复原文章记录 |
| 后台生成 | 发送后切到首页，顶栏显示原文章生成中；首页仍为待办会话，输入可编辑，发送禁用 |
| 后台完成 | 顶栏显示原文章已完成；点击后回到原文章与原会话，建议没有进入首页会话 |
| 停止生成 | 点击停止后显示停止状态，恢复可重发的输入 |
| 新对话 / 历史 | 当前对象新建空对话，历史入口可返回原会话 |
| 首页确认调整 | 阅读事项从今天 20:00 更新为明天 20:00 |
| 首页勾选 | 勾选一项后顶栏 2/6 → 3/6，首页说明和周一统计同步更新 |
| 命例归属 | 林川切到沈禾进入独立引导，返回恢复林川对话 |
| 命盘定位 | 点击“在盘面中定位日主”，日柱出现定位高亮 |
| 收起与焦点 | 收起后 `aria-expanded=false`，焦点回到顶栏 AI 入口，再次打开成功 |
| 宽度键盘调整 | 聚焦分隔条后按方向键，助手宽度相应变化 |
| 窄窗滚动 | 对话内部可滚动到应用按钮，输入区保持可见 |
| 控制台 | 最后一次读取未发现 warning / error |

## 3. 布局矩阵

对首页、博客、命理分别检查雾灰 / 冷灰 / 暖砂主题与 1280×820 / 1024×680 两档容器，共 **18 组通过**。

- 1280×820：并排停靠；1024×680：覆盖展开。
- 实际容器宽高与预设一致；默认助手宽度 380px。
- 文档、主内容、助手均未检测到横向溢出。
- 输入表单上下边界始终在助手区域内。
- 1024 窄窗关闭助手后，主内容宽度约 919px。

完整 DOM 几何记录：[assistant-layout-checks.json](../design/mockups/_shots/assistant-layout-checks.json)。该检查覆盖预览容器的响应式状态，不等同于原生 Electron 窗口、浏览器缩放和所有操作系统的兼容测试。
