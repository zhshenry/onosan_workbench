## 两套共同的布局约定(需求落点)

- 左侧两层导航:图标栏(第一层)+ 分组目录(第二层:效率工具 / 创作工坊 / 生活),左上角 logo
- 顶栏:左侧「日程」时间条(含进行中高亮)+「待办」完成度胶囊;右上角搜索/通知/设置/头像
- 首页 = 内嵌 To-Do-List 模块(今日待办、今日日程、本周概览、逾期置顶、优先级/标签)
- 文档中心 = Office 预览/编辑入口(含"在系统应用中打开");内置浏览器 = 独立会话 + 地址栏 + 标签页
- 终端、自媒体制作、个人网页设计、个人游戏设计、八字排盘 = 规划中占位
